# 📱 PhonePe Personal Financial Analyzer

An AI-powered personal financial analysis app built using Python and Streamlit.

## Features
- Upload transaction CSV
- Automatic expense categorization
- Savings rate calculation
- Expense prediction
- Financial health insights
- PDF report generation

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit
- ReportLab

## Run Locally

pip install -r requirements.txt
streamlit run app.py
